# /money-retro — Weekly Retrospective

A short, honest weekly review that ends with one focus — not a backlog.

## Structure

1. **Decided** — decisions made this week (pull from `/money-save` checkpoints).
2. **Shipped** — what actually went live or out the door. Concrete artifacts only.
3. **Stalled** — what was planned but didn't move, and the *real* reason
   (blocked, unclear, avoided, over-scoped).
4. **Unused skills** — which parts of the pipeline went untouched. Is a phase
   being neglected (e.g. lots of building, zero distribution)?
5. **Focus** — the *single* most important thing for next week. One, not ten.

## Workflow

- Read the week's checkpoints and learnings.
- Be honest about stalls — name avoidance when it's avoidance.
- Spot imbalance (all build / no growth, all planning / no shipping).
- End with one focus and the first action toward it.

## Value Quantification

- **Honesty:** names *why* things stalled, not just that they did.
- **Balance:** flags neglected phases before they become the bottleneck.
- **Focus:** forces one priority for the week instead of a guilt-list.

## Output

- Decided / Shipped / Stalled / Unused-skills summary
- Next week's single focus
- Tomorrow's first action: [specific task]

## Rules

- One focus for the week — resist listing everything.
- Count only real shipped artifacts under "Shipped".
- Call out avoidance honestly; the retro is useless if it's flattering.
