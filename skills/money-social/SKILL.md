# /money-social — Social Media

Build an audience and drive traffic with platform-native content — each channel
has its own rules.

## Per-platform playbook

- **X / Twitter** — hook in the first line, thread for depth, one idea per post,
  build in public with real numbers.
- **LinkedIn** — story → lesson → takeaway; professional but human; hook before
  the "...see more" fold.
- **Reddit** — give value first, never overtly sell; respect each subreddit's
  norms; comments > posts for trust.
- **Product Hunt** — launch-day playbook: strong tagline, first comment with the
  founder story, mobilize early supporters, reply to every comment.

## Hook-writing frameworks

Open with one of: surprising result · contrarian claim · named pain · "I spent
X and learned Y" · number + timeframe · before/after. The first line decides
whether anyone reads the rest.

## Workflow

1. Pick the platform that fits where buyers actually are.
2. Choose a hook framework and write the native format.
3. Plan a sustainable cadence (consistency beats bursts).
4. Engage replies — distribution comes from conversation, not broadcast.

## Value Quantification

- **Native reach:** content fits each platform's algorithm and norms.
- **Scroll-stopping:** hook frameworks win the first line where attention is decided.
- **Sustainable:** a realistic cadence one person can actually keep.

## Rules

- Never cross-post identical copy — adapt per platform.
- On Reddit/communities, give value before any ask.
- Lead every post with a real hook, not a warm-up sentence.
