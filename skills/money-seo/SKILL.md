# /money-seo — SEO + GEO

Win both classic search ranking *and* citations inside AI-generated answers.

## Traditional SEO

1. **Keyword & intent** — target queries real buyers type; match the page to the
   intent (informational vs. transactional).
2. **On-page** — title, H1, meta description, internal links, descriptive URLs,
   one clear topic per page.
3. **Technical** — crawlability, sitemap, canonical tags, mobile, Core Web
   Vitals, no broken links, structured data (schema.org).
4. **Content depth** — answer the query better than the current top results;
   cover the related sub-questions.

## GEO (AI-search optimization)

AI answer engines cite sources that are clear, factual, and easy to extract:

- **Answer the question directly** near the top — quotable, self-contained.
- **Structure for extraction** — clear headings, definitions, lists, and FAQs.
- **Be citable** — concrete facts, numbers, and statements an LLM can lift.
- **Entity clarity** — name the product, problem, and category explicitly.
- **Freshness & authority** — keep facts current; earn mentions elsewhere.

## Value Quantification

- **Compounding traffic:** organic rankings keep paying after the work is done.
- **AI visibility:** structured, citable content surfaces in ChatGPT/Perplexity answers.
- **Intent-matched:** pages target buyer queries, not just volume.

## Rules

- Map every target page to a specific query and intent.
- Write the direct answer high on the page for both readers and AI.
- Don't keyword-stuff — depth and clarity rank, padding doesn't.
